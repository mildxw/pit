# Практическая работа №7. Часть 1. Дебаг Фибоначчи.

## Тема
Отладка программы различными способами.

## Цель работы
Изучить основные способы отладки программ в Microsoft Visual Studio.

## Ход работы
В ходе выполнения практической работы была проведена отладка консольного приложения «Фибоначчи».

Были использованы следующие средства отладки Microsoft Visual Studio:
- точки останова (Breakpoints);
- пошаговое выполнение программы (Step Over);
- шаг с заходом в метод (Step Into);
- продолжение выполнения программы (Continue);
- просмотр локальных переменных (Locals);
- просмотр значений переменных (Watch);
- окно вывода (Output Window).

В процессе работы были добавлены XML-комментарии к методам программы.

## Результат
Были изучены основные возможности отладки программ в Microsoft Visual Studio и выполнена отладка консольного приложения.
