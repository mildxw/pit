# Практическая работа №7. Часть 1. Дебаг Буквы.

## Задание
Отладка консольного приложения «Буквы».

## Цель работы
Изучить основные способы отладки программ в Microsoft Visual Studio.

## Ход работы
В ходе выполнения практической работы была проведена отладка консольного приложения «Буквы».

В процессе отладки был выполнен запуск программы в режиме отладки, установлены точки останова и выполнен пошаговый анализ работы программы.

## Использованные способы отладки
В ходе работы были использованы следующие средства отладки Microsoft Visual Studio:

- точки останова;
- пошаговое выполнение программы;
- Step Over;
- Step Into;
- Continue;
- просмотр значений переменных;
- окно Locals;
- окно Watch;
- анализ вывода консоли.

## Результат
Были изучены основные способы отладки программы в Microsoft Visual Studio. Приложение было запущено и проверено в режиме отладки.
