# Практическая работа №7. Часть 1. Дебаг Галактики.

## Задание
Отладка консольного приложения «Галактики».

## Цель работы
Изучить основные способы отладки программ в Microsoft Visual Studio.

## Ход работы
В ходе выполнения практической работы была проведена отладка консольного приложения «Галактики».

В программе были обнаружены и исправлены ошибки:
- свойство `GalaxyType` имело тип `object`, из-за чего невозможно было обратиться к свойству `MyGType`;
- в операторе `switch` была опечатка: вместо символа `I` использовался символ `l`, из-за чего тип галактики `Irregular` не выводился.

## Использованные способы отладки
В ходе работы были использованы следующие средства отладки Microsoft Visual Studio:

- точки останова;
- пошаговое выполнение программы;
- Step Into;
- Step Over;
- Continue;
- просмотр значений переменных через подсказки;
- окно Locals;
- окно Watch;
- перезапуск приложения в режиме отладки;
- анализ вывода консоли.

## Результат
Ошибки в программе были найдены и исправлены. После отладки приложение корректно выводит названия галактик, расстояния до них и типы галактик.
